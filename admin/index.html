Клиентские аккаунты

Добавить клиента

Каждому клиенту создаются свои ключи, TUN и адрес. Профиль передавайте только по защищённому каналу.

Параметры транспорта

Для Android: MTU TUN не менее 1280 и постоянный Identifier. MTU внешнего пакета должен вмещать TUN с шифрованием и заголовками. Изменение клиента перезапускает активный туннель: затем скачайте и заново импортируйте профиль на клиенте. Заблокированный туннель остаётся остановленным. Настройки по умолчанию влияют только на новые аккаунты; ранее настроенные ручные службы редактируются отдельно.

Учётная запись администратора

После смены браузер запросит новые учётные данные. Пароль хранится на сервере только в виде хеша.

Счётчики трафика показывают данные с последнего запуска процесса. «Внешний трафик» включает служебные и отклонённые ICMP-пакеты. Для ранее настроенных клиентов доступны просмотр и блокировка; их ключи и конфигурация остаются в исходных каталогах.
